# Glossary

| Term | Meaning |
| --- | --- |
| ACV | Annual contract value: the yearly value of a customer's contract |
| AE | Account executive: runs demos, negotiates, closes deals |
| API | A way for programs to request data or actions from another system |
| ARR / MRR | Annual / monthly recurring revenue |
| Association | A link between CRM records (contact ↔ company), optionally with a role label |
| Backoff (exponential) | Waiting longer after each failed retry: 1, 2, 4, 8 s |
| Batch endpoint | One request that handles many records |
| BDR / SDR | Business / sales development rep: finds prospects, books first meetings |
| Bearer token | A secret string in the `Authorization` header that proves who you are |
| Buying committee | Everyone involved in a purchase decision (champion, economic buyer, technical evaluator) |
| CAC | Customer acquisition cost |
| Cache | Stored results reused instead of re-fetched or recomputed |
| Champion | The person inside the account pushing for your product |
| Churn | Customers who leave |
| CISO | Chief Information Security Officer |
| Clay | A GTM tool for enrichment waterfalls, AI columns and pushing data to the CRM |
| Compliance | Proving you follow a standard or law |
| Control | One specific security safeguard checked in an audit |
| CRM | The shared database of accounts, contacts, deals and activities |
| CSM | Customer success manager: keeps customers happy, renewals |
| CTE | A named sub-query in SQL (`WITH x AS (...)`) |
| Cursor (pagination) | A token pointing to the next page of results |
| DataFrame | A pandas table |
| Deal stage | Where an opportunity stands (demo done, proposal sent…) |
| DORA | EU digital operational resilience law for finance |
| Dry run | Running everything except the final write |
| ELT / ETL | Extract-load-transform / extract-transform-load |
| Endpoint | A specific URL of an API |
| Enrichment | Filling missing fields from data providers |
| Entity resolution | Deciding which records refer to the same real company or person |
| Field ownership | Which system is allowed to set each field |
| Firmographics | Facts about a company (industry, size, location, funding) |
| Foreign key | A column pointing to another table's primary key |
| GDPR | EU law on personal data |
| GTM | Go-to-market: everything that turns a product into revenue |
| HMAC signature | A code computed with a shared secret proving a webhook came from the real sender |
| ICP | Ideal Customer Profile |
| Idempotent | Running twice gives the same result as running once |
| Inbound / outbound | They come to you / you reach out first |
| Incremental load | Processing only new or changed records since the last run |
| Intent | Signals that a company may buy now |
| ISO 27001 | International standard for information security management; certifiable |
| Jitter | A small random extra wait so retries don't collide |
| JSON | Labelled text data; dictionaries and lists in Python |
| Lifecycle stage | Lead, MQL, SQL, opportunity, customer… |
| LLM | Large language model, like Claude |
| MQL / SQL (leads) | Marketing qualified lead / sales qualified lead |
| NaN | pandas' "missing number"; not valid JSON |
| NIS2 | EU cybersecurity law covering many sectors |
| Normalisation | Putting values in one consistent format |
| Pagination | Getting big lists one page at a time |
| Persona | A type of person you sell to (CTO, head of IT) |
| Pipeline (sales) | All open deals and their value |
| Pipeline (data) | Code that moves data from sources to destinations |
| Polling | Repeatedly asking "anything new?" |
| Primary key | A column uniquely identifying each row |
| Property | A field on a CRM record |
| Rate limit | A cap on requests per time window; exceeding it returns 429 |
| Retry-After | A response header saying how many seconds to wait |
| Reverse ETL | Pushing warehouse data back into tools like the CRM |
| RevOps | Revenue operations: CRM configuration, reporting, process |
| Round-robin | Handing out leads to reps in turn |
| Routing | Assigning leads to reps automatically |
| Scope | A permission attached to an API key |
| Sequence (cadence) | A planned series of outreach steps over days |
| Service key | HubSpot's current way to authenticate API calls for one account |
| Signal | A visible event suggesting a company needs you now |
| Single source of truth | The one place everyone trusts for correct data |
| SOC 2 | US-originated security audit report |
| Speed to lead | Time from an inbound lead arriving to first contact |
| Survivorship rule | Which value wins when duplicate records merge |
| TAM | Total addressable market |
| Technographics | The tools a company uses |
| TISAX | Security assessment for the automotive supply chain |
| Token (AI) | A piece of text (~4 characters) used to measure AI input and output |
| Upsert | Update if the record exists, create it if not |
| Warehouse | A database for analysis across all tools (BigQuery, Snowflake) |
| Waterfall (enrichment) | Trying providers in order until one returns a value |
| Webhook | A system calling your URL the moment an event happens |
